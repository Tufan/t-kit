# Add-ons

Things this kit doesn't do out of the box, and how to add them when you need
them.

Don't read these until you need one. The kit works without any of them.

- [sending-email.md](sending-email.md) - real sign-in emails instead of the terminal
- [google-login.md](google-login.md) - sign in with Google
- [file-uploads.md](file-uploads.md) - let people upload photos or documents
- [scheduled-jobs.md](scheduled-jobs.md) - make something happen every day
- [payments.md](payments.md) - take money
